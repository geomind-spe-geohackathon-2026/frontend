`.claude/` holds what agents and Claude Code sessions read about this repo; `docs/` holds what
people read. Read both, and the project-wide context in the project root (`../AGENTS.md`,
`../.claude/` with the shared memory, `../docs/`). Layout and naming rules:
`../.claude/README.md`.

| Folder     | Holds                                                                                                                                        |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `docs/`    | (none yet) Reference for the code lives in this repo's `docs/`, listed in `AGENTS.md`.                                                       |
| `notes/`   | Current work on this repo: the brief, the next-round list, the WEBSITE I handover.                                                           |
| `archive/` | Finished work: task prompts (`prompts/`), phase prompts (`phases/`), old notes (`notes/`). Read only when the history of a decision matters. |
